# Полировка Telegram-бота: красивые сообщения и меню

## Статус: к исполнению (новый тред)

Цель: все сообщения и меню бота — максимально красивые и информативные. `send`/`edit_text` уже шлют `parse_mode: HTML` (`telegram/api.rs`) — арсенал `<b>/<i>/<code>/<pre>/<blockquote expandable>/<a>/<s>` доступен без переделок. Генераторы сообщений: `handlers.rs` (`day_message`, `week_message`, `debts_message`, напоминания), строки — `texts.rs` (ru/en/be).

## A. Инфраструктура (первый коммит)

- Хелпер `esc()` для HTML-экранирования пользовательских данных (имена, заметки, ссылки) — сейчас `<`, `>`, `&` в данных ломают разметку.
- Общий билдер «карточки занятия»: время в `<code>` (ровные колонки), имя `<b>`, предмет/длительность/оплата второй строкой, ссылка `<a>`, заметки в `<blockquote expandable>` (сворачиваемый спойлер Telegram).

Макет карточки:

```
<b>15:00–16:00</b> · <b>Иван</b>
Математика · 60 мин · 💰 не оплачено
<a href="...">🔗 ссылка</a>
<blockquote expandable>Длинная заметка…</blockquote>
```

## B. День / Неделя

- Заголовок `<b>📅 Четверг, 30 октября</b>` + строка статистики (занятий / проведено / ожидается по валютам).
- Неделя — группировка по дням с подзаголовками `<b>Пн 27</b>`; отменённые занятия `<s>зачёркнуты</s>`.

## C. Напоминания

- Заголовок `<b>🔔 Занятие через 1 час</b>`, поля компактно.
- После inline-действия — `edit_text` в итоговое состояние (`✅ Проведено` + компактная карточка) вместо снятия кнопок: чат не захламляется.

## D. Должники

- Группировка по ученику; `<pre>`-блок с ровными колонками сумм; итог по ученику `<b>`; общий итог в конце.

## E. Настройки бота

- Inline-меню вместо текста: поля сообщения и интервалы напоминаний как тумблеры `✅/⬜`, перерисовка через `edit_markup` того же сообщения.

## F. Проверки и приёмка

- Все новые строки в `texts.rs` на трёх языках.
- `/verify` после каждого пункта (A→F, коммит на пункт).
- Визуальная приёмка скриншотами из Telegram (desktop + mobile).
