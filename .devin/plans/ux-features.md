## A. Ctrl+K палитра команд

- Глобальный диалог по `Ctrl+K`/`Cmd+K` (keydown в App).
- Реестр команд: переход на страницы (Сегодня/Календарь/Ученики/Финансы/Напоминания/Журнал/Настройки), действия (новое занятие, к сегодняшнему дню), поиск учеников и занятий (простой substring по имени/предмету, без внешних зависимостей; допустим `cmdk`, но сначала попробовать свою реализацию — зависимость не обязательна).
- Стиль — в духе существующих Dialog-компонентов; переводы ru/en/be.

## B. Drag&drop в недельном виде — полировка

- СНАЧАЛА проверить, что уже есть: в волне 3 упоминался «dnd-перенос» — вероятно drag уже работает (`CalendarViews`, `onMoved`). Если работает — этот пункт сводится к выявленным при тесте дефектам (перенос экземпляра серии vs серии, визуальная обратная связь).

## C. Офлайн телефонной страницы

- Страница `http_server.rs` (axum :45321): кэшировать последний успешный payload в `localStorage` телефона; при недоступности сервера показывать кэш + баннер «данные на HH:MM, офлайн».
- Без service worker — простой fetch + fallback на кэш.

## Критерий приёмки

- Палитра: Ctrl+K открывает, команды работают, поиск находит ученика/занятие, Esc закрывает; клик по найденному занятию открывает карточку.
- Офлайн: при выключенном приложении телефон показывает последнее расписание с пометкой времени.
- `/verify` зелёный после каждой фичи; визуальная приёмка.
