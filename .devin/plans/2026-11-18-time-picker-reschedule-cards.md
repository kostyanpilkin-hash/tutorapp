## Баги (подтверждены кодом)

1. **Залипший `pendingScope`** — `LessonFormDialog.tsx`: `setPendingScope(scope)` в `RecurrenceScopeDialog.onSelect` нигде не сбрасывается. Кнопка «Сохранить» → `save(pendingScope || undefined)` → после первого выбора «только это занятие» все последующие сохранения серий молча применяют `this` до перезапуска приложения.
2. **Мёртвая кнопка при повторном переносе** — при редактировании exception-строки («только это занятие» → `createLesson`) бэкенд исключает из overlap-проверки слот `parent::inst`, но не саму exception-строку → её текущее положение конфликтует с новым временем → `OVERLAP` ошибка.
3. **OVERLAP-ошибки невидимы** — `api.call()` подавляет тосты для `OVERLAP:` → сохранение падает молча, кнопка выглядит «мёртвой».
4. **30-минутная сетка** — `RescheduleLessonDialog` генерирует кандидатов с шагом 30 мин и скрывает занятые, ручного ввода нет.
5. **Перенос не находится** — только правый клик → контекстное меню.

## *** пользователя

- Перенос: поле даты + круговые часы + свободный ввод (сетку слотов убрать).
- Пересечения: единая политика «предупредить, но разрешить» во всех трёх местах.

- «Перенести»: кнопка в форме + иконка при наведении на карточку в расписании.

## Реализация

### 1. Фикс `pendingScope` и смежного состояния (LessonFormDialog)

- В `useEffect` на `open` добавить `setPendingScope(null)`; после успешного `doSave` и в `onClose` — сброс `pendingScope`, `scopeOpen`, `overlapWarning`.
- Убрать `pendingScope` из кнопки «Сохранить» (вызывать `save()` без аргументов); pendingScope остаётся только как мостик scope→payment-prompt.

### 2. Фикс overlap-исключения на бэкенде (create_lesson)

- В `create_lesson` при наличии `recurrence_parent_id`+`recurrence_instance_date` расширить исключение: кроме `parent::inst` исключить существующие exception-строки того же слота (запрос `lessons WHERE recurrence_parent_id=?` + сравнение локальной даты `instance_date` через `parse_any_date`, как в `occurrences::collect`).
- Проверка должна идти ДО `dedupe_exceptions_for_instance` — сейчас так и есть, просто расширяем набор исключений.
- Тест cargo: exception на 18:00, повторный create с `recurrence_parent_id`+`instance_date` на 17:40 — не должен вернуть OVERLAP.

### 3. Видимость ошибок и порядок сохранения (LessonFormDialog)

- `doSave` обернуть ошибку: `OVERLAP:` → показать тост/инлайн-предупреждение с именами (не молчать).
- Порядок: сначала scope-диалог (если серия), потом overlap-проверка с корректным `excludeId` для выбранного скоупа, потом запись. Warning-бар с именами конфликтующих + «Сохранить всё равно» — закрепить у футера, чтобы было видно без скролла.

### 4. Компонент `TimePicker` (круговой циферблат)

- Новый `src/components/ui/time-picker.tsx`: значение `"HH:mm"` (24ч):
  - текстовое поле с маской `ЧЧ:ММ` — свободный ввод любого времени, валидация;
  - кнопка-иконка часов раскрывает диск: внешнее кольцо часы 0–11, внутреннее 12–23 → затем кольцо минут с шагом 5; выбранное значение и кнопки ±5/±1 мин для произвольных минут;
  - стили из токенов приложения (`primary`, `muted`, `border`), кнопки как у чипов напоминаний.
- Подключить везде вместо `<Input type="time">`: `LessonFormDialog`, `RescheduleSeriesDialog`, новый `RescheduleLessonDialog`, `SettingsPanel` (digest/quiet время).

### 5. `RescheduleLessonDialog` — редизайн

- Убрать генерацию слотов и массовые `checkOverlaps`.
- Поля: дата (`type="date"`), время (`TimePicker`), длительность (readonly-подпись), конец вычисляемый (`HH:mm → HH:mm`).
- Живая overlap-проверка на изменении времени (debounce ~300мс): предупреждение с именами, кнопка активна → при сохранении `force` через persistLessonChange.
- Для серий сохранить текущее поведение (exception «только это»); «перенести серию» остаётся `RescheduleSeriesDialog` с тем же `TimePicker`.

### 6. Кнопка «Перенести»

- В футере `LessonFormDialog` (между «Удалить» и «Отмена/Сохранить»): для разового → сразу `RescheduleLessonDialog`; для серийного → маленький выбор «только это»/«с этого и дальше» → соответствующий диалог.
- Иконка `CalendarClock` при наведении на карточку занятия в `CalendarViews` (рядом с существующим контекстным меню): разовое → reschedule-диалог; серийное → выбор скоупа.

### 7. Вкладки в карточках

`LessonFormDialog` — вкладки (Radix Tabs):
- **Основное**: ученики, предмет, дата/время/длительность, повторение, статус+оплата
- **Ссылки и заметки**: ссылка, ссылка на материалы, заметки (урок + по ученикам), материалы
- **Напоминания**: чипы напоминаний
- Футер (Удалить / Перенести / Отмена / Сохранить) и overlap-warning — вне вкладок, закреплены.

`StudentFormDialog` — вкладки:
- **Контакты**: фото, имя, телефон, email, мессенджер, родители, дата рождения
- **Занятия**: таймзона, стоимость/валюта/длительность, оплаченные, ссылка по умолчанию, цвет
- **Заметки**: notes + lessonNote
- Вложенные диалоги (валюта/ссылка) — без изменений.
