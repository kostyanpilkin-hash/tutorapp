## A. Форма занятия — секции (первый коммит)

Поля группируются в карточки-секции с заголовком `[иконка] Название` (стиль — как секции настроек):

- **«Кто и когда»** (`👥`): выбор учеников + чипы выбранных, предмет, дата+время+длительность. Время и длительность в одной строке; рядом автоподсчёт конца: `15:00 → 16:00` (из start+duration, просто текст).
- **«Повторение»** (`🔁`): select none/weekly остаётся; при weekly — блок с **пилюлями дней недели** вместо checkbox-label: круглые/rounded-full кнопки `Пн Вт Ср Чт Пт Сб Вс` toggle (bg-primary при выборе). Окончание — тот же select + условные поля.
- **«Оплата»** (`💵`): цена+валюта; при >Nученика — чекбокс «разные цены» и его поля.
- **«Ссылки и заметки»** (`🔗`): ссылка на урок, материалы URL, заметки, заметки учеников, материалы — сохранить порядок и текущие textarea/LinkifiedText.
- **«Напоминания»** (`🔔`): вместо «количество + 3 select» — **toggle-чипы**: `за день · за час · за 30 мин · за 15 мин · за 5 мин · в начале` (все REMINDER_PRESETS). Нажатие добавляет/убирает из `reminderValues` (сортировка по убыванию минут, дедуп — как сейчас). Количество = сколько включено (без select «1/2/3»).
- **«Статус и оплата»** (`📌`): вместо двух select — **сегментированные чипы**: статус — `[Заплан.][Провед.][Не сост.][Отмена]` с цветом активного (completed→зелёный, no_show→янтарный, cancelled→muted зачёркнутый), оплата — `[Не оплачено|💰 Оплачено]` segmented.

Подвал без изменений: overlap-warning, delete/cancel/save.

## B. Карточка ученика (второй коммит)

Правая панель `StudentsPanel` переструктурируется:

- **Hero-шапка**: `StudentAvatar` (64px) + имя + **строка контекста**: «След. занятие: чт 15:00» (из `nextLesson`), бейдж долга `🟡 45 USD` (если `finance.debt` непуст), бейдж `🟢 Предоплачено: N` (если `paidLessons>0`). Кнопка «+ Занятие» — accent/default; «Мессенджер», «Изменить», «Архив» — компактные иконки с title (lucide: `MessageCircle`, `Pencil`, `Archive`/`ArchiveRestore`).
- **Контакты — строки-действия**: иконка + значение + справа маленькие кнопки: телефон → `tel:`-ссылка «Позвонить» + копировать; мессенджер → «Открыть» (`messengerUrl`); email → `mailto:`; родитель (name+phone/messenger) — так же. Стиль — `SettingRow`-подобные строки.
- **Заметки** — как сейчас (muted-блок + LinkifiedText), только заголовок с иконкой.
- **Финансы**: AmountBlock'и → цветные акцентные карточки (мягкий фон: `bg-green-500/10`, `bg-amber-500/10`, `bg-blue-500/10` вместо голых рамок) + иконка в заголовке. Кнопка «Применить предоплату» остаётся в заголовке блока.
- **История**: каждая строка — **цветная точка статуса** перед датой (completed 🟢 green-500, no_show 🟠 amber-500, cancelled ⚫ muted + зачёркнутый текст, scheduled 🔵 blue-500 для предстоящих); **группировка по месяцам** — подзаголовки `НОЯБРЬ 2026` (date-fns `format LLLL yyyy` + locale) перед первой строкой месяца; ближайшее предстоящее занятие — подсветка `bg-primary/5`. Быстрые кнопки ✔/💰 — остаются.
- Список учеников слева — не трогаем.

## C. Сворачиваемые заметки в TodayWidget (третий коммит)

Сейчас `lessonStudentNotes` и `lesson.notes` рендерятся полотном (`LinkifiedText`, `TodayWidget.tsx:246-251`) — карточка занятия раздувается.

- Локальный state expanded-note по id занятия (`Set<string>` в компоненте).
- Заметки > ~120 символов или >Nстрок: CSS-clamp (`line-clamp-2`) + кнопка-линк «…ещё» / «Свернуть» (новые i18n-строки). Клик переключает — без отдельного state-менеджмента.
- `LinkifiedText` продолжает рендерить ссылки кликабельными в обоих состояниях.
