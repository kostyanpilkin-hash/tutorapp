# История изменений

Все значимые изменения проекта TutorApp. Даты — по коммитам.

## 2026-10-30 (вечер)

### Журнал действий
- Удаление занятия и целой серии теперь архивируются и попадают в журнал с кнопкой «Отменить»
- Отметки на экземплярах серии (статус/оплата/перенос) логируются через сравнение с шаблоном серии — без эвристик
- Восстановление из архива пишет запись «восстановлено»
- Статусы и оплата локализованы (ru/en/be), даты — по языку интерфейса
- Пагинация «Показать ещё» по Nзаписей; хранится не более 5000 последних записей

### Телефонное расписание
- Дедупликация занятий по идентификатору экземпляра, а не по имени/времени
- Выбор адреса: предпочитается интерфейс с маршрутом по умолчанию; в настройках список всех LAN-адресов
- Кнопка «Сбросить ключ доступа» — старая ссылка перестаёт работать

### Календарь
- Убраны режимы «День» и «Список»; остались «Неделя» и «Месяц»

## 2026-10-30

### Журнал действий («История»)
- Единый журнал действий в приложении: отдельный пункт «История» в левом меню
- Записываются: создание/обновление/удаление занятий и серий, переносы, смены статусов и оплаты, предоплата, погашение долга, создание/архивация учеников, изменения настроек
- Дифф-логирование: записи отражают реальное действие («оплата изменена», «статус изменён», «перенесено»), а не техническую операцию
- Читаемые значения (даты/статусы/оплата словами), раскрытие подробностей по клику
- Кнопка «Отменить» на записях об удалении — восстановление через архив

### Расписание на телефоне
- Локальный HTTP-сервер (axum, порт 45321) внутри приложения — тумблер в настройках
- Страница расписания для телефона: ближайшие дни, статусы занятий и оплаты, PWA (добавление на «Домой»)
- Развёртка рекуррентных серий на сервере (BYDAY/INTERVAL/UNTIL/COUNT, исключения)
- Авторизация по токену, QR-код ссылки в настройках
- Исправлен выбор IP при включённом VPN (туннельные адаптеры фильтруются)

## 2026-10-29

### Темы оформления
- 10 фирменных тем: Купертино, Дискорд, Спотифай, Гитхаб, Редактор, Слэк (тёмные); Мак, Ноушн, Материал, Мика (светлые)
- Глубокая стилизация: радиусы, шрифты, сайдбар, тени, скроллбары, форма кнопок и полей
- «Вау-эффект»: Liquid Glass (полупрозрачность, блюр, световая кромка) для Мак/Купертино; анимация жидкого стекла на «Сегодня»; канал-стили Дискорда; статус-бар VS Code; FAB Материала

### Занятия и серии
- Удаление серии = «это и последующие»: обрезка правила UNTIL, история сохраняется
- Архив удалений с полными снимками строк + отмена ~12 сек (toast «Отменить»)
- Восстановление из архива: исходные id, правила, связи, напоминания
- Контекстное меню: «Перенести ›» и «Удалить ›» как подменю на всех занятиях
- Правки подменю (обрезание при наведении)

### Прочее
- Промо-видео (Remotion): тёмные слайды в стиле Apple, реальные скриншоты приложения, сгенерированная музыка
- Сборка под macOS: .app/.dmg бандлы + гайд для новичков
