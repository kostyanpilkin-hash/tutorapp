# История изменений

Все значимые изменения проекта TutorApp. Даты — по коммитам.

## 2026-10-30 (вечер, 6)

### Финансовые агрегаты — на единый экспандер
- Финансовый отчёт и финансы ученика теперь разворачивают серии через `occurrences::expand_weekly_starts_local` — тот же local-tz алгоритм, что использует `collect`; `expand_weekly_starts` (UTC-якорь) удалён, `recurrence.rs` свёрнут до `is_weekly` + `intervals_overlap`
- Фикс краевого случая: серии с BYDAY и якорем около полуночи местного времени (или в таймзонах с переходом на летнее время) в финансах считались по UTC-дням — теперь по локальным, как в календаре/боте
- Проверка на копии реальной базы: все Nсерия разворачиваются идентично старому алгоритму (в данных нет полуночных якорей) — финансовые цифры не изменились; дифф-харнес остался в `occurrences::realdb_tests`
- Все три старых экспандера устранены: приложение, бот, телефон, планировщик, пересечения и финансы работают на единой семантике серий

## 2026-10-30 (вечер, 5)

### Убрана фронтовая развёртка серий (G1-4b)
- Локальный `expandLessons` и флаг `fe.expand=local` удалены: расписание во всех видах (Сегодня/календарь/ученик/напоминания) разворачивает только бэкенд — единый источник правды с ботом и телефонной страницей
- Замороженная копия старого экспандера перенесена в `parity.test.ts` как эталон: продолжает сторожить регрессии `occurrences::collect` на копии реальной базы
- Тесты экспансии убраны из `recurrence.test.ts` (их роль — backend-тесты + паритет); остались тесты хелперов (parse/build/UNTIL/COUNT, id-утилиты)

## 2026-10-30 (вечер, 4)

### Планировщик и проверка пересечений — на единый экспандер
- Напоминания на ПК теперь разворачивают расписание через `occurrences::collect` — тот же код, что и приложение/бот/телефон; ключи напоминаний и снуза не изменились
- Фикс: серии, созданные около полуночи по местному времени, напоминали не в тот день недели — старый экспандер якорил слоты по UTC-дню; теперь по локальному
- `find_overlaps` (проверка пересечений при создании/переносе) переведён на `collect` — одинаковое понимание серий, исключений и отменённых слотов во всех частях приложения
- Остались на старом `expand_weekly_starts`: финансовые агрегаты (`finance.rs`, `get_student_finance`) — миграция отдельной волной

### Инструменты агента
- Скиллы `.devin/skills/release` (пайплайн релиза: проверки → сборка → тихая установка → changelog → коммит/пуш) и `.devin/skills/parity` (паритет развёртки на копии реальной БД)
- `AGENTS.md`: подводные камни (`nul`, NSIS `/S`, bash vs PowerShell)

## 2026-10-30 (вечер, 3)

### Единая развёртка повторяющихся занятий (G1)
- Новая команда `get_expanded_lessons(from, to)`: расписание теперь разворачивает бэкенд через общий модуль `occurrences` — один источник правды для приложения, телефонной страницы и бота
- Экземпляры серий отдаются с id вида `parent::ISO` (формат `toISOString()`), как их ждёт интерфейс — действия над экземплярами (статус/оплата/перенос/удаление) работают без изменений
- «Сегодня», календарь, панель напоминаний и карточка ученика читают готовое расписание с бэкенда; локальная развёртка `expandLessons` остаётся как запасной путь (localStorage `fe.expand=local` или автоматически при ошибке запроса)
- Фикс: «Отложить напоминание» для повторяющихся занятий молча не работало — ключи снуза теперь нормализуются (`parent::ISO` → id родителя, время → rfc3339) и совпадают с планировщиком
- Паритет бэкенд↔фронт проверен на копии реальной базы: списки занятий идентичны на всех диапазонах (день/неделя/месяц/2 года — до Nзанятий); регресс-тесты: `src/lib/parity.test.ts` + `scripts/parity-prepare.mjs` + 7 backend-тестов

## 2026-10-30 (вечер, 2)

### Telegram-бот
- Привязка: токен от @BotFather → 6-значный код → /start боту. Кнопки «Проверить связь» и «Отвязать»
- Постоянная клавиатура: Сегодня / Завтра / Неделя / Утренняя сводка / Вечерний итог / Должники / Настройки (+ slash-команды)
- Напоминания: отдельный набор от ПК (по умолчанию за 1 час), в боте переключаются 15м/30м/1ч/2ч/1д; состав сообщения настраивается (ученик/время/ссылка/предмет/длительность/заметки/оплата/цена)
- Inline-кнопки под напоминанием: ✅ Проведено / ❌ Не состоялось / 💰 Оплачено / 🚫 Отменить (с подтверждением); для серий применяется к экземпляру; действия пишутся в Журнал с пометкой «telegram»
- Утренняя сводка в 09:00 («Сегодня свободно 🎉» при пустом дне); вечерний итог и список должников по запросу
- Тихие часы 23:00–07:00 (кроме напоминаний), «догон» пропущенных напоминаний при запуске приложения
- Язык бота = язык приложения (ru/en/be); работает через long polling — не нужны входящие порты и VPN-сети
- Фикс: бот не отвечал до привязки (поллинг не стартовал); «Должники» — та же логика, что в Финансах (учитываются «не пришёл», стоимость >0, оплата из lesson_students)
- Фикс: развёртка расписания в боте теперь идентична приложению (исключающий UNTIL, лучшее исключение на слот); неделя = пн–вс
- Красивое отображение: заголовок + блоктекст-статистика, иконки статусов (🕓✅❌🚫), двухстрочные занятия (время+детали), кнопки действий к каждому занятию, улучшенные «Должники» и «Вечерний итог»

### Инфра

## 2026-10-30

### Журнал действий («История»)
- Единый журнал действий в приложении: отдельный пункт «История» в левом меню
- Записываются: создание/обновление/удаление занятий и серий, переносы, смены статусов и оплаты, предоплата, погашение долга, создание/архивация учеников, изменения настроек
- Дифф-логирование: записи отражают реальное действие («оплата изменена», «статус изменён», «перенесено»), а не техническую операцию
- Читаемые значения (даты/статусы/оплата словами), раскрытие подробностей по клику
- Кнопка «Отменить» на записях об удалении — восстановление через архив

### Расписание на телефоне
- Локальный HTTP-сервер (axum, порт 45321) внутри приложения — тумблер в настройках
- Страница расписания для телефона: ближайшие дни, статусы занятий и оплаты, PWA (добавление на «Домой»)
- Развёртка рекуррентных серий на сервере (BYDAY/INTERVAL/UNTIL/COUNT, исключения)
- Авторизация по токену, QR-код ссылки в настройках
- Исправлен выбор IP при включённом VPN (туннельные адаптеры фильтруются)
