# Как собрать TutorApp на MacBook — гайд для новичка

Этот гайд написан для человека, который никогда не собирал программы. Выполняйте шаги по порядку, ничего не пропуская. Каждый шаг объясняет, что вы делаете и зачем.

**Важно понимать сразу:** сделать файл для Mac можно только на самом Mac. На Windows это невозможно технически — Apple разрешает собирать программы для своих *** только на своих компьютерах.

---

## Часть 0. Что такое «Терминал» и как им пользоваться

Всё делается в программе **«Терминал»** — это окно, куда вводят команды текстом.

**Как открыть Терминал на Mac:**
1. Нажмите на клавиатуре `Cmd` (⌘) + `Пробел` — откроется поиск Spotlight.
2. Начните печатать: `терминал` или `Terminal`.
3. Нажмите Enter — откроется окно с мигающим курсором.

**Как вводить команды:**
- Копируете строку команды из этого гайда → вставляете в Терминал (Cmd+V) → нажимаете Enter.
- Команда «работает», когда внизу появляются строки текста или ничего не происходит (успех часто выглядит как тишина).
- Если всплывает красная ошибка — читайте её текст и сверяйтесь с таблицей проблем в конце гайда.

> ⚠️ Вставляйте команды **по одной строке**. Текст после `#` — это комментарий-подсказка, его вводить не нужно.

## Шаг 1. Установить инструменты разработчика

Для сборки нужны три вещи: инструменты Apple, язык Rust и Node.js.

### 1.1. Инструменты Apple (Xcode Command Line Tools)

В Терминале введите:

```bash
xcode-select --install
```

Появится окно «Установить инструменты командной строки?» → нажмите **«Установить»** → «Согласиться». Ждите 5–20 минут. Когда курсор вернётся — готово.

> Если команда выдала `already installed` — значит, уже установлено, идите дальше.

### 1.2. Менеджер программ Homebrew

Homebrew — это программа, которая устанавливает другие программы одной командой.

В Терминале вставьте **целиком одной строкой**:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Скрипт спросит пароль — введите **пароль от входа в Mac** и нажмите Enter (при вводе пароля символы не отображаются — это нормально, просто печатайте).

В конце Homebrew может написать `Next steps` с *** строками вида `eval "$(/opt/homebrew/bin/brew shellenv)"` — скопируйте и выполните их тоже.

Проверка:

```bash
brew --version
```

Должно вывести что-то вроде `Homebrew 4.x.x`.

### 1.3. Node.js — нужен для сборки внешнего вида приложения

```bash
brew install node
```

Проверка:

```bash
node -v
npm -v
```

Должны вывести версии вроде `v22.x.x` и `10.x.x`. Если `node: command not found` — закройте и заново откройте Терминал.

### 1.4. Rust — язык, на котором написан «мозг» приложения

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

После `Welcome to Rust!` спросит вариант установки — нажмите `1` (стандартная) и Enter.

В конце выполните:

```bash
source "$HOME/.cargo/env"
```

Проверка:

```bash
rustc -V
cargo -V
```

## Шаг 2. Получить код программы

### 2.1. Если есть интернет-репозиторий (GitHub и т.п.)

```bash
cd ~/Desktop        # зайти на рабочий стол (можно в любую другую папку)
git clone <ссылка-на-репозиторий> tutor-app
cd tutor-app
```

### 2.2. Если репозитория в интернете нет

Перенесите папку проекта с Windows-компьютера на Mac любым способом (флешка, облако, AirDrop). Скопируйте папку `tutor-app` целиком, кроме подпапок `node_modules` и `src-tauri/target` — они большие и пересоздадутся автоматически.

Затем в Терминале:

```bash
cd ~/Desktop/tutor-app    # путь куда положили — подставьте свой
```

> Подсказка: путь к папке можно не печатать вручную — перетащите папку из Finder прямо в окно Терминала, путь подставится сам.

## Шаг 3. Одна правка в файле настроек (обязательно)

В настройках сборки сейчас прописан идентификатор `com.tutor.app`. На macOS суффикс `.app` — это расширение самих приложений, и он ломает сборку установщика.

**Как исправить:**

1. В папке проекта найдите файл `src-tauri/tauri.conf.json`.
2. Откройте любым текстовым редактором (TextEdit, VS Code — что есть).
3. Найдите строку `"identifier": "com.tutor.app"`.
4. Замените на `"identifier": "com.tutor.tutorapp"`.
5. Сохраните файл (Cmd+S).

> Технические детали для любопытных: идентификатор зашивается в приложение, путь к данным и разрешения на уведомления. Менять его нужно до первой сборки — потом для *** это будет «другое приложение».

## Шаг 4. Установить зависимости проекта

В Терминале, находясь в папке `tutor-app`:

```bash
npm install
```

Это скачает все библиотеки, которые нужны проекту (в папку `node_modules`). Занимает 2–10 минут, много текста — это нормально. Дождитесь возврата курсора.

## Шаг 5. Собрать приложение

```bash
npm run tauri build
```

Первый раз сборка идёт **долго** — 10–25 минут (Rust компилирует весь проект с нуля). Будет много текста и прогресс-бары — ждите. Успех выглядит так:

```
Finished `release` profile
    Finished 2 bundles at:
        .../bundle/macos/TutorApp.app
        .../bundle/dmg/TutorApp_0.2.0_aarch64.dmg
```

**Где лежит результат** (относительно папки проекта):

- Приложение: `src-tauri/target/release/bundle/macos/TutorApp.app`
- Установщик для передачи: `src-tauri/target/release/bundle/dmg/TutorApp_0.2.0_aarch64.dmg`
  - (на Intel-Mac вместо `aarch64` будет `x86_64` — тоже нормально)

**Быстрый способ открыть эту папку:** скопируйте и выполните в Терминале:

```bash
open src-tauri/target/release/bundle
```

Откроется окно Finder — там папки `macos/` и `dmg/` с результатами.

## Шаг 6. Проверить, что приложение работает

```bash
open src-tauri/target/release/bundle/macos/TutorApp.app
```

Что проверить:

- Открылось окно с календарём — основа работает.
- **Уведомления**: macOS спросит «разрешить уведомления?» — нажмите «Разрешить». Напоминания будут приходить через стандартные уведомления Mac.
- **Иконка в меню-баре** (верх экрана справа) — клик даёт меню «Открыть / Выход».
- **Автозапуск**: переключатель в настройках приложения включает запуск при входе в ***.
- **Где данные**: база в `~/Library/Application Support/com.tutor.tutorapp/` — можно перенести данные с Windows-копии, скопировав туда файлы `tutorapp.db` и папку `students/`.

## Шаг 7. Установка на Mac

1. Смонтируйте `.dmg`: двойной клик по `TutorApp_0.2.0_aarch64.dmg` в Finder.
2. В открывшемся окне перетащите `TutorApp.app` на папку `Программы` (Applications).
3. Запускайте из `Программы` как обычное приложение.

**Если при первом запуске пишет «разработчик не проверен»:**
- Правый клик по иконке → «Открыть» → в диалоге ещё раз «Открыть». Больше спрашивать не будет.

## Таблица типичных проблем

| Сообщение | Что случилось | Что делать |
|---|---|---|
| `command not found: brew` | Homebrew не в PATH | Закрыть и заново открыть Терминал; либо выполнить строки `eval "$(...brew shellenv)"` из конца установки Homebrew |
| `xcrun: error` при сборке | Нет инструментов Xcode | Шаг 1.1 |
| Предупреждение про `.app` в identifier | Не сделан шаг 3 | Заменить `com.tutor.app` → `com.tutor.tutorapp` в `tauri.conf.json` |
| `.dmg` не появился | Нет иконки `.icns` | В папке проекта: `npx tauri icon src-tauri/icons/icon.png` и собрать заново |
| Нет уведомлений | macOS запретил | Системные настройки → Уведомления → TutorApp → включить |
| Приложение не открывается на чужом Mac | Подпись Apple отсутствует | ПКМ → Открыть; или раздел «Для раздачи другим» ниже |
| `command not found: npm` | Node не установлен или Терминал старый | Шаг 1.3, потом перезапустить Терминал |

## Что на Mac будет работать иначе или не работать

- Тосты-напоминания — обычные уведомления macOS (без фирменного вида как на Windows).
- Кнопка «Создать ярлык на рабочем столе» — ничего не делает (на Mac так не принято).
- Ссылки на мессенджеры — открываются в браузере Mac.

## Для раздачи приложения другим людям (необязательно)

Чтобы у других людей приложение запускалось без «непроверенного разработчика», нужен платный аккаунт разработчика Apple ($99/год) и подпись кода. Это уже отдельная история — для личного пользования необязательно. Подробности в разделе «Подпись и нотаризация» официальной документации Tauri.
