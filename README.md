# TutorApp

Настольное приложение для репетитора на Windows (Tauri 2 + React + SQLite).

## Возможности

- **Календарь**: виды «день», «неделя», «месяц», «список»; drag-and-drop перенос занятий между днями и по времени
- **Повторяющиеся занятия**: еженедельные серии с исключениями для отдельных дат (перенос, отмена, изменение одного занятия из серии)
- **Перенос занятия**: диалог «Перенести» с поиском свободных слотов 08:00–22:00 с шагом 30 минут и проверкой пересечений
- **Ученики**: фото, цвета, часовые пояса (время ученика показывается с GMT-смещением), индивидуальная стоимость и валюта (USD/EUR/BYN/RUB), предоплаченные занятия, архив
- **Финансы**: статистика за день/неделю/месяц/год/произвольный период, суммы по каждой валюте отдельно (без конвертации), вкладка «Долги» с кнопкой «Оплачено» у каждой строки, история изменений, детализация по предметам и ученикам
- **Напоминания**: всплывающие уведомления Windows (toast) с отложенным напоминанием (snooze), настраиваемое время до занятия
- **Интерфейс**: темы оформления, языки — русский, английский, белорусский
- **Работа в трее**: сворачивание в системный трей, автозапуск с Windows, ярлык на рабочем столе

## Данные

База SQLite хранится в `%AppData%\TutorApp\tutor.db`. При запуске автоматически создаётся резервная копия `tutor.db.bak`; ручной бэкап доступен в «Настройках».

## Разработка

```bash
npm install
npm run tauri dev      # запуск в режиме разработки
npm run build          # сборка фронтенда
npm run test           # тесты фронтенда (vitest)
npm run lint           # eslint + clippy
cd src-tauri && cargo test   # тесты бэкенда
```

## Сборка установщика

```bash
npm run build:installer
```

Установщики (MSI и NSIS) складываются в `installers/<дата>/`.
