# TutorApp

Настольное приложение для репетитора на Windows (Tauri 2 + React).

## Возможности v1

- Календарь: день, неделя, месяц, список
- Создание занятий с учеником, предметом, стоимостью (USD/BYN/RUB), ссылкой
- Повторяющиеся занятия (еженедельно)
- Drag-and-drop перенос в календаре
- Предупреждение о пересечении занятий
- Напоминания Windows (системный трей)
- Виджет «Сегодня» — 3 ближайших занятия
- Темы: светлая, тёмная, яркая
- Языки: русский, английский, белорусский
- SQLite автосохранение в `%AppData%/TutorApp/`

## Запуск

```bash
npm install
npm run tauri dev
```

## Сборка установщика

```bash
npm run tauri build
```
